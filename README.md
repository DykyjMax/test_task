1. Встановити Python. Рекомендовано розгорнути Venv.
2. Клонувати репозиторій.
3. Встановити Django і усі інші необхідні модулі із файлу "r.txt" (requirements.txt).
4. Встановити базу даних postgresql і створити нову базу даних для даного проекту.
5. Вписати дані доступу до БД у settings.py в розділі DATABASES, або створити файл локальних налаштувань проекту.
6. Провести міграції командами "python manage.py makemigrations" і "python manage.py migrate".
7. Створити пороіль адміністратора командою "python manage.py createsuperuser"
8. Проект розгорнуто і налоштовано.
